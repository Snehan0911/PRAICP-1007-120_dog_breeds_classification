Project ID: PRAICP-1007-120

Dog Breeds Classification

An enterprise-grade deep learning computer vision system designed to classify 120 canine breeds from photographic images with transparent visual explainability.

Project Purpose & Vision

Identifying dog breeds is an archetypal fine-grained visual categorization challenge. Unlike generic object recognition (e.g., distinguishing a dog from a bicycle), fine-grained breed classification requires resolving minimal inter-class visual discrepancies (e.g., distinguishing an Alaskan Malamute from a Siberian Husky) while accommodating substantial intra-class variation (different coat colors, puppy vs. adult poses, and diverse environmental lighting).

This project implements a complete, end-to-end AI/ML pipeline following strict software engineering and machine learning rigor: from raw image validation and reproducible data splitting, to transfer learning model training, comprehensive evaluation, explainable AI, and responsive web deployment.

The Dataset: Stanford Dogs

20,580 Verified Color Photographs
120 Canine Breeds Represented
0 Corrupted or Unreadable Files

Derived from Stanford University's landmark fine-grained vision benchmark (Khosla et al.), the dataset contains images collected across the globe representing breeds from the American Kennel Club (AKC) and Fédération Cynologique Internationale (FCI). Every individual file was verified during Milestone 3 to ensure byte-level integrity.

Professional Engineering Standards

Zero Data Leakage: Training, validation, and holdout test partitions (70 / 15 / 15) were generated via stratified random splitting before any model development. Test images were never seen during training or hyperparameter tuning.
Empirical Integrity: Every reported accuracy figure, confusion matrix, loss curve, and inference latency reflects real execution results without simulated or mocked numbers.
Model Interpretability: Integrated Grad-CAM explainability demystifies deep neural network predictions by calculating gradient activations at convolutional feature maps.
Automated Testing: 30 standalone pytest unit tests cover data loading, preprocessing, model architecture compilation, evaluation metrics, image validation, and prediction ranking.

Operational Considerations & Model Boundaries

  • Purebred Bias: The model is optimized for purebred dogs representing the 120 classes in the Stanford dataset. Mixed-breed dogs (mutts) will be matched to their most morphologically similar ancestral breeds.
  • Non-Canine Images: The current classifier is a closed-set 120-class model. Uploading non-dog images will yield low-confidence predictions among the 120 breeds. An out-of-distribution (OOD) detector is recommended for future production iterations.
  • Extreme Occlusion: Heavy obstruction, extreme low-light, or extreme motion blur can degrade predictive accuracy.
