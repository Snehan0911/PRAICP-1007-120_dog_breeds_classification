Deep Learning Model Architecture

Technical specifications and mathematical foundations of the transfer learning engine powering Dog Breeds Classification.

MobileNetV2 Backbone

Inverted Residual Blocks

Unlike standard residual networks (ResNet) that compress channels before expanding, MobileNetV2 expands to high dimensions in intermediate layers, applies a depthwise convolution, and projects back to low-dimensional linear bottlenecks.

Depthwise Separable Convolutions

Decomposes standard 2D convolution into depthwise spatial filtering per channel followed by pointwise $1 \times 1$ linear projection, slashing computation by approximately 88% while retaining expressive power.

Transfer Learning Head

Leverages 1.4 million pre-trained ImageNet image priors. The backbone remains frozen during Stage 1 feature extraction, allowing our custom 154K parameter head with dropout (0.3) to specialize in canine fine-grained traits.

Depthwise Separable Efficiency

Given input feature map of size $D_F \times D_F \times M$ and kernel $D_K \times D_K$:

Ratio = ½ Costdepthwise+pointwise / Coststandard = 1/N + 1/DK2

For $3 \times 3$ kernels ($D_K = 3$) and $N \gg 9$ output channels, computation reduces by a factor of 8 to 9, allowing lightweight sub-second predictions on standard CPU threads.

Optimization & Objective Function

Trained using Categorical Cross-Entropy Loss with Adam optimizer:

Loss = − ∑c=1120 yc · log(pc) + λ ∑ w2

Coupled with an adaptive learning rate scheduler (ReduceLROnPlateau) monitoring validation loss to escape saddle points.
